
# Smart Library Management System

A desktop Library Management application developed using **Java Swing**. It allows users to manage books through a simple graphical interface with persistent CSV storage.

## Features

- Add new books
- Search books by ID or title
- Delete books
- Issue and return books
- Automatic data saving using CSV
- User-friendly Java Swing GUI

## Tech Stack

- Java
- Java Swing
- OOP (Object-Oriented Programming)
- Collections (ArrayList)
- File Handling (CSV)

## Project Structure

Book.java – Book model

LibraryManager.java – Business logic

LibraryUI.java – GUI interface

Main.java – Application entry point

books.csv – Data storage

## How to Run

1. Compile the project:
   javac *.java

2. Run the application:
   java Main
